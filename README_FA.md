# RIBAR AI VIDEO STUDIO — Mobile MVP

این پروژه یک وب‌اپ مستقل و موبایل‌محور است. به Rich Shoes، وردپرس یا ویرایشگر عکس قبلی متصل نیست.

## وضعیت این نسخه
- رابط فارسی و RTL
- طراحی واکنش‌گرا برای موبایل
- انتخاب عکس و ویدیو از گالری
- پیش‌نمایش رسانه انتخابی
- انتخاب سبک و نسبت تصویر
- ساخت استوری‌بورد پیشنهادی اولیه
- PWA و کش پایه برای نصب/بازگشایی
- هنوز موتور رندر MP4، حذف پس‌زمینه هوشمند و تولید موشن AI متصل نشده‌اند.

## انتشار رایگان با GitHub Pages
1. یک حساب GitHub بساز.
2. یک Repository جدید و Public با نام `ribar-mobile-studio` ایجاد کن.
3. فایل‌های داخل این پوشه را در ریشه Repository بارگذاری کن.
4. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن.
5. Branch را `main` و Folder را `/ (root)` قرار بده و Save کن.
6. پس از انتشار، GitHub یک لینک رایگان به شکل `https://USERNAME.github.io/ribar-mobile-studio/` می‌دهد.

## نصب روی آیفون
1. لینک منتشرشده را در Safari باز کن.
2. دکمه Share را بزن.
3. Add to Home Screen را انتخاب کن.

## وضعیت قابلیت‌ها
- تایم‌لاین چندصحنه‌ای و خروجی ویدیویی هنوز در نسخه منتشرشده فعال نیستند؛ تا زمان انتشار و تست، آن‌ها را قابلیت آماده محسوب نکنید.

## نکته فنی
GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند و سرور رندر یا API اجرا نمی‌کند. برای رندر ابری و قابلیت‌های AI در مرحله بعد باید یک سرویس backend جداگانه اضافه شود. فایل‌های رسانه در این نسخه فقط در حافظه همان صفحه مرورگر نگهداری می‌شوند؛ با بستن صفحه، تضمینی برای ماندگاری آن‌ها وجود ندارد.
